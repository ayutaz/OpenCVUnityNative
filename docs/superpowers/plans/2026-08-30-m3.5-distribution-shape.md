# M3.5 実装計画 — 配布の形と、実用に必要な最小の穴

> **エージェント向け:** この計画は `superpowers:subagent-driven-development` か
> `superpowers:executing-plans` でタスク単位に実施する。手順は `- [ ]` で追える。

**ゴール:** 1 つの tarball に Desktop 3 platform の binary が入り、OpenUPM へ登録できる形になり、
メモリ上の画像 byte 列を encode / decode でき、サポート期限内の Unity で検証されている。

**アーキテクチャ:** 配布物の作り方だけを変え、package の構造は変えない。
`Runtime/Plugins/` は既に platform ごとのディレクトリに分かれているので、
**3 つの木を重ねてから固める**段階を `release.yml` に足す。C ABI には
`imgcodecs` の 2 関数を、既存の「2 回呼びで必要サイズを問う」作法で足す。

**技術スタック:** PowerShell 7、CMake 3.25+、MSVC / Clang / GCC、GoogleTest、xUnit、
Unity 6000.3.16f1（IL2CPP / EditMode）、GitHub Actions。

**Spec:** [ロードマップ](../../roadmap.md) の「M3.5 — 配布の形と、実用に必要な最小の穴」節。
完了条件 6 件はそこが正本であり、この計画はそれを実施可能な単位に割ったものである。

## Global Constraints

Spec とリポジトリの不変条件のうち、**全タスクに掛かる**もの。各タスクの要件はこれを暗黙に含む。

- **C ABI が唯一の native contract。** `cv::Mat*` や STL 型を境界の外に出さない。
- **例外を ABI の外へ伝播させない。** `ocvu_status` を返す `extern "C"` 関数は
  `OCVU_TRY_BEGIN` / `OCVU_TRY_END` で囲む。**シグネチャは `extern "C" ocvu_status ocvu_名(`
  までを 1 物理行に置く** —— `.claude/hooks/check-exception-barrier.sh:54` は 1 行前提で、
  折り返すと黙って素通しする。
- **`Runtime/Interop` と `Runtime/Core` は `UnityEngine` を参照しない。**
  UnityEngine 依存は `Runtime/UnityIntegration/` にのみ置く。
- **新しい `.ps1` / `.psm1` は先頭に `[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()`。**
- **`git add -A` / `git add .` は hook が拒否する。** 変更したファイルを明示的に指定する。
- **検査を足したら壊して落ちるところを見る**（`prove-a-check-works`）。
  「著者が列挙した形だけを見る検査」を作らない。
- **`OCVU_ABI_VERSION` は bump しない。** 関数の追加は
  `docs/abi-ownership-and-versioning.md` §2 で「bump しない変更」に分類されている。
- ローカルの緑は近似で、**merge 可否は CI が決める。**

## Task 2: `imgcodecs` を C ABI に出す（完了条件 5）

**着手前の実測:** `cmake/FindOpenCvUnityDeps.cmake:35` は `COMPONENTS core imgproc` だけで、
**`imgcodecs` はリンクされていない。** リンク行にも DLL にも無い（`imread` の文字列が 0 件）。
component を足せばリンクは通り、**その時点ではサイズは変わらない**（参照されないため）。

**Files:**
- Modify: `cmake/FindOpenCvUnityDeps.cmake`
- Create: `native/tests/test_imgcodecs.cpp`, `native/src/ocvu_imgcodecs.cpp`
- Modify: `native/include/opencv_unity_native.h`, `native/CMakeLists.txt`, `native/tests/CMakeLists.txt`
- Create: `Packages/.../Runtime/Core/CvCodecs.cs`, `tests/Managed/.../ImgcodecsTests.cs`
- Modify: `Packages/.../Runtime/Interop/NativeMethods.cs`

**Interfaces:**
- Produces:
  - `ocvu_status ocvu_imencode(ocvu_mat_handle src, const char* ext, uint8_t* buffer, int32_t buffer_size, int32_t* out_required_size)`
  - `ocvu_status ocvu_imdecode(const uint8_t* data, int64_t length, int32_t flags, ocvu_mat_handle dst)`
  - C#: `CvCodecs.Encode(CvMat, string) -> byte[]`、`CvCodecs.Decode(byte[], CvImreadFlags, CvMat)`

**所有権の契約（先に決める）:** encode の出力サイズは呼ぶ側に分からない。
**native が確保した blob を handle で返す形は採らない** —— それは
`docs/abi-ownership-and-versioning.md` §1 に無い新しい所有権の種類を増やす。
既に 3 か所で使っている**2 回呼びの作法**（`OCVU_STATUS_BUFFER_TOO_SMALL` +
`out_required_size`）をそのまま使う。

```c
/* imdecode の読み込み方。OpenCV の cv::IMREAD_* と同じ値であることは
   実装側の static_assert が固定する。 */
#define OCVU_IMREAD_GRAYSCALE 0
#define OCVU_IMREAD_COLOR     1
#define OCVU_IMREAD_UNCHANGED (-1)

/* Mat を画像形式に符号化して buffer へ書く。
 *
 * **2 回呼ぶ。** 1 回目は buffer=NULL / buffer_size=0 で呼び、
 * out_required_size に必要なバイト数を受け取る（戻り値は
 * OCVU_STATUS_BUFFER_TOO_SMALL）。2 回目にその大きさの buffer を渡す。
 * 成功時は out_required_size に実際に書いたバイト数が入る。
 *
 * 出力の所有権は呼ぶ側にある。native は buffer を保持しない。
 * ext は ".png" のように先頭のドットを含む拡張子。空文字列は
 * OCVU_STATUS_INVALID_ARGUMENT。
 */
OCVU_API ocvu_status ocvu_imencode(ocvu_mat_handle src, const char* ext,
                                   uint8_t* buffer, int32_t buffer_size,
                                   int32_t* out_required_size);

/* 符号化された画像 byte 列を復号して dst へ入れる。
 * dst は既存の handle で、中身は置き換わる（大きさ・型も変わる）。
 * data は 1 回の呼び出しの内側でのみ読む（借用）。
 */
OCVU_API ocvu_status ocvu_imdecode(const uint8_t* data, int64_t length,
                                   int32_t flags, ocvu_mat_handle dst);
```

- [ ] **Step 4: 実装を書く**

`native/src/ocvu_imgcodecs.cpp` を新規作成し、`native/CMakeLists.txt` の
`OCVU_SOURCES` に足す。**`extern "C" ocvu_status ocvu_imencode(` までを 1 行に置く**
（hook が 1 行前提のため）。

```cpp
#include "opencv_unity_native.h"
#include "ocvu_error.h"
#include "ocvu_mat_table.h"

#include <opencv2/imgcodecs.hpp>
#include <vector>
#include <string>

/* OpenCV 側の値と食い違ったらビルドで止める。 */
static_assert(OCVU_IMREAD_GRAYSCALE == cv::IMREAD_GRAYSCALE, "IMREAD_GRAYSCALE drift");
static_assert(OCVU_IMREAD_COLOR == cv::IMREAD_COLOR, "IMREAD_COLOR drift");
static_assert(OCVU_IMREAD_UNCHANGED == cv::IMREAD_UNCHANGED, "IMREAD_UNCHANGED drift");

extern "C" ocvu_status ocvu_imencode(ocvu_mat_handle src, const char* ext, uint8_t* buffer, int32_t buffer_size, int32_t* out_required_size) {
    OCVU_TRY_BEGIN
    if (out_required_size == nullptr) { return OCVU_STATUS_NULL_POINTER; }
    *out_required_size = 0;
    if (ext == nullptr) { return OCVU_STATUS_NULL_POINTER; }
    if (ext[0] == '\0') { return OCVU_STATUS_INVALID_ARGUMENT; }
    if (buffer_size < 0) { return OCVU_STATUS_INVALID_ARGUMENT; }
    if (buffer_size > 0 && buffer == nullptr) { return OCVU_STATUS_NULL_POINTER; }

    cv::Mat* mat = ocvu::mat_table_get(src);
    if (mat == nullptr) { return OCVU_STATUS_INVALID_HANDLE; }

    std::vector<uchar> encoded;
    try {
        if (!cv::imencode(std::string(ext), *mat, encoded)) {
            ocvu::set_last_error(OCVU_STATUS_OPENCV_ERROR, "imencode returned false");
            return OCVU_STATUS_OPENCV_ERROR;
        }
    } catch (const cv::Exception& e) {
        ocvu::set_last_error(OCVU_STATUS_OPENCV_ERROR, e.what());
        return OCVU_STATUS_OPENCV_ERROR;
    }

    if (encoded.size() > (size_t)INT32_MAX) { return OCVU_STATUS_INVALID_ARGUMENT; }
    const int32_t needed = (int32_t)encoded.size();
    *out_required_size = needed;
    if (buffer_size < needed) { return OCVU_STATUS_BUFFER_TOO_SMALL; }

    std::memcpy(buffer, encoded.data(), (size_t)needed);
    return OCVU_STATUS_OK;
    OCVU_TRY_END
}

extern "C" ocvu_status ocvu_imdecode(const uint8_t* data, int64_t length, int32_t flags, ocvu_mat_handle dst) {
    OCVU_TRY_BEGIN
    if (data == nullptr) { return OCVU_STATUS_NULL_POINTER; }
    if (length <= 0 || length > (int64_t)INT32_MAX) { return OCVU_STATUS_INVALID_ARGUMENT; }

    cv::Mat* out = ocvu::mat_table_get(dst);
    if (out == nullptr) { return OCVU_STATUS_INVALID_HANDLE; }

    try {
        const cv::Mat view(1, (int)length, CV_8UC1, const_cast<uint8_t*>(data));
        cv::Mat decoded = cv::imdecode(view, flags);
        if (decoded.empty()) {
            ocvu::set_last_error(OCVU_STATUS_OPENCV_ERROR, "imdecode produced an empty Mat");
            return OCVU_STATUS_OPENCV_ERROR;
        }
        *out = decoded;   // 借用はここで終わる。decoded は自分のメモリを持つ
    } catch (const cv::Exception& e) {
        ocvu::set_last_error(OCVU_STATUS_OPENCV_ERROR, e.what());
        return OCVU_STATUS_OPENCV_ERROR;
    }
    return OCVU_STATUS_OK;
    OCVU_TRY_END
}
```
